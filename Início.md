
Bem vindo ao SAP Practical Guide. 

Este guia ou base de conhecimento tem como objetivo servir de apoio ao estudo do sistema SAP, voltado para as funções de consultor técnico de SAP.
Também ser como quick reference guide para diversas áreas do SAP.

O objetivo não é ter uma base de conhecimento exaustiva do SAP, já que o mesmo conta com descrições detalhadas para quase todos os componentes, mas sim como um resumo e guia.

Esta base foi criada por Nilson Cardoso em 04/11/2025 e foi criada para o SAP4HANA
